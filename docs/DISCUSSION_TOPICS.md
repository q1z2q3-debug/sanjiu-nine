## 话题 2 · 数理探讨：等价类、算子与空间的深层性质

**分类建议：General**

**标题**：数理探讨：19683 格上的错/综/互/变，等价类与空间性质

**正文**：

锁定的公理与算子（不修改）：
- 错卦 `F_C`（逐爻取反，对合）、综卦 `F_Z`（反转，对合）、错综 `F_CZ`、互卦 `F_H`（5 维内核）、变爻 `F_B`（+1/−1→0，0→+1）

已确认的关键结果：
- 等价组总数 **5002**，组大小分布 {1:1, 2:161, 4:4840}
- Burnside：`(19683 + Fix(F_C)=1 + Fix(F_Z)=243 + Fix(F_CZ)=81) / 4 = 5002`
- 图网络：连通分量 1；`F_C` 9841 边、`F_Z` 9720 边、单爻动 `F_B` 118098 边；最大度 19、平均度 14.0
- 聚类 8 类（14 维 = 9 原卦 + 5 互卦）对标八卦

想和大家探讨：
- 为什么等价组大小只有 {1,2,4} 三种？存在"自错/自综"的卦（Fix(F_C)=1、Fix(F_Z)=243）意味着什么？
- `F_H` 输出 5 维内核，不补齐 9 维——这个"降维投影"保留了哪些信息，丢失了哪些？
- 变爻 `F_B` 在图上形成了 118098 条边——这些"一步可达"的状态对检索/推理的意义？

欢迎带计算或直觉来讨论。

## 话题 3 · 使用反馈：装包、构建 APK、或想加什么

**分类建议：Q&A（或 Ideas）**

**标题**：使用反馈 / 求助：安装、构建、功能建议

**正文**：

欢迎反馈任何使用中遇到的问题或想要的特性：

- **符号体系**：`python3 trigram/trigram.py` 复算；`pip install -r requirements.txt` 装依赖（numpy）。
- **APK 插件**：`pip install sanjiu-apk-builder`，然后
  ```bash
  sanjiu-apk scaffold --out ./app --package com.my.poetry --name "我的诗库"
  sanjiu-apk build --dir ./app --jdk <JDK17> --sdk <ANDROID_SDK>
  ```
- 遇到问题请带上：操作系统 / Python 版本 / JDK / SDK 版本 / 报错日志。
