# 三元九维 · 项目总览

> 从 **19683 格认知空间**出发：用三元（+1/0/−1）× 九维构建一套可定位、可泛化、可推演、可检索的符号体系，并把它接进 agent 认知层、落地为诗词创作与 APK。

---

## 一、缘起：一个认知空间

一切的起点是一个问题：**19683 格是不是很好的认知空间？**

三态（阳 / 中和 / 阴）在 9 个维度上组合，得到 **3⁹ = 19683** 种状态。这个空间天然具备两种被需要的性质：

- **可定位**：每个状态是一个 9 维向量，可用空间距离衡量任意两个状态"有多像"；
- **可泛化**：三态爻覆盖"显 / 衡 / 隐"，比二值（0/1）多一层居间与势能，能表达更细的过渡与耦合。

于是问题变成：能不能把这 19683 格升级为大模型 / agent 的**认知层**——符号向量 ↔ 象义的可逆映射，让"状态"既能被机器定位，又能被人理解。

本项目用一条主线回答它：**三元九爻符号体系（数理）→ 象义层（释义）→ 认知层桥接（trit↔卦）→ 应用（诗词 APK + 原创诗）**。

---

## 二、逆向周易：提炼范式，不照搬规则

先把经典《周易》的二元六爻体系逆向拆解，提炼**建模范式**，再迁移到三元九爻公理（不直接照搬二元规则）：

| 范式 | 周易中的体现 | 三元九爻中的迁移 |
|---|---|---|
| 有限离散格 | 64 卦 = 2⁶ | 19683 卦 = 3⁹ |
| 对偶变换 | 错卦（阴阳互变） | `F_C` 逐爻取反 |
| 序列反转 | 综卦（上下颠倒） | `F_Z` 序列反转 |
| 内核投影 | 互卦（取中间） | `F_H` 输出 5 维内核 |
| 变爻机 | 动爻变卦 | `F_B` 单爻/多爻发动 |
| 等价关系网络 | 卦的等价类 | `{G, F_C, F_Z, F_CZ}` |

核心洞见：**符号的"意义"不只存在于单个状态，更存在于状态之间的变换关系**——这就是"象义"可以从数理中长出来的原因。

---

## 三、锁定公理（不可修改）

1. **爻态语义**：阳(+1)·显/向外/生发｜中和(0)·居间/耦合/稳态｜阴(−1)·隐/向内/收敛
2. **错卦 `F_C`**：+1↔−1，0 不变；`F_C(F_C(G))=G`
3. **综卦 `F_Z`**：序列反转；`F_Z(F_Z(G))=G`
4. **错综 `F_CZ`**：先综后错
5. **互卦 `F_H`**：剔除上/下爻，取中心连续 5 爻，输出 5 维（不补 9 维）
6. **变爻 `F_B`**：+1/−1→0，0→+1；支持 1~9 爻同时发动

**单元测试（全过，未改公理）**，对样例卦 `[+1,+1,0,−1,+1,0,−1,−1,0]`：
`F_C=[−1,−1,0,+1,−1,0,+1,+1,0]`，`F_Z=[0,−1,−1,0,+1,−1,0,+1,+1]`，`F_CZ=[0,+1,+1,0,−1,+1,0,−1,−1]`，`F_H=[0,−1,+1,0,−1]`，第 5 爻动 `[+1,+1,0,−1,0,0,−1,−1,0]`。

## 四、关键数理结果

- **全集**：19683 卦
- **独立等价组**：**5002**（组大小 {1:1, 2:161, 4:4840}；Burnside 校验 `(19683+1+243+81)/4 = 5002`）
- **符号图网络**：19683 节点、连通分量 1；`F_C` 9841 边、`F_Z` 9720 边、单爻动 `F_B` 118098 边；最大度 19、平均度 14.0
- **逆向检索**：自然语言 → 目标 9 维向量 → 欧氏距离 Top-N 邻近卦 + 全套推演
- **聚类**：14 维（9 原卦 + 5 互卦）KMeans 8 类对标八卦，成员 {2430,2430,2430,3159,2430,1863,2430,2511}，合计 19683

## 五、象义层与语义解码

- **`oracle.py`**：爻位意象词库 + 体势（阳实外发/阴凝内敛/阴阳相济）+ 内核定机（互卦极性），导出 5002 等价组卦辞 `oracle_full.csv`；并支持变爻断辞（每爻位配阶段与吉凶偏向）。
- **`llm_decoder.py`**：双通道——真实 LLM（配 API key 自动启用）或主模型注入。口语描述 → 9 维向量。示例：口语「项目胎死腹中…宜收敛蓄力、守中待动」→ 解码为 `[−1,−1,−1,−1,0,−1,−1,0,+1]`，命中「阴凝内敛·潜」，语义严丝合缝。

---

## 六、认知层桥接

- **`bridge.py`**：把 agent 决策的认知态 `trit('0'/'1'/'2')` 与三元卦互转（同一 3⁹ 空间），`cognitive_oracle(trit)` 输出卦体 + 等价组 + 象义 + 断辞。
- **`demo_bridge.py`**：跑真实 agent 决策轨迹，逐状态注解卦象。
- **`capital-agent/src/capital_agent/semantic.py`**：语义嵌入 + 场景相关动作检索的记忆升级——**结论：语义检索在场景相关任务上优于纯格子几何检索**（这正是 19683 格认知层该有的形态）。

## 七、应用：诗词分类 APK + 三元原创

- **图文界面**：卦象图画（阳实线/阴断线/中和菱形）、年龄段 chip、三元推演、经典分类 ⇄ 三元原创双模式。
- **语料**：100 首经典（5 年龄段 × 20）+ 20 首**三元原创**（每首由一个创作卦的象义驱动，5 年龄段 × 本卦/错卦/动中爻/动境界爻）。
- **一键构建**：见配套工具 **sanjiu-apk-builder**（脚手架 + 构建器，PyPI 可装，CI 自动构建）。

## 九、边界与原则

1. 数理公理、算子映射**固定**；推演、图结构、聚类、象义释义可自由创作。
2. 人文卦辞是**文本创作**，不能反过来改动底层数理。
3. 互卦固定输出 5 维内核，不补齐 9 维。
4. 分布式协作：欢迎提交 Issue / PR，共同完善符号体系与工程落地。
